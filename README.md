# Accident Detection and Smart Alert System

## Project Overview
The Accident Detection and Smart Alert System is designed to detect road accidents and provide alerts with location information.

## Features
- Accident detection
- GPS location tracking
- Smart alert notification
- Accident record storage
- Accident history management

## Project Structure
```text
Accident_Detection_System/
│
├── alert.py
├── detector.py
├── gps.py
├── main.py
├── storage.py
├── accident_records.csv
├── history.csv
├── requirements.txt
└── README.md
```

## Technologies Used
- Python
- GPS
- CSV File Handling

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```
